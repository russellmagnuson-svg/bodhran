How to hook this up to GarageBand
  1. Open Audio MIDI Setup (in /Applications/Utilities).
  2. Window → Show MIDI Studio, double-click IAC Driver, tick Device is online, and make sure there is one bus.
  3. Reload this page, then pick the IAC bus in Port above.
  4. In GarageBand, create a Software Instrument track with a drum kit. It listens to incoming MIDI on the selected track.
  5. Tick Send MIDI and press play. Adjust the note numbers above until they land on sounds you like in the kit.

Web MIDI works in Chrome and Edge. Safari does not support it, so this panel stays disabled there.
