# Concertina samples

These single notes of a modern 30-key Anglo concertina with steel reeds are cut
from **"Demonstration of the note range of an Anglo Concertina"** by
**Alwayswonder**, Wikimedia Commons, 11 April 2023:
https://commons.wikimedia.org/wiki/File:Demonstration_of_the_note_range_of_an_Anglo_Concertina.webm

Licensed **CC BY-SA 4.0** (https://creativecommons.org/licenses/by-sa/4.0/).
These samples are an adaptation of that recording, so they carry the same
licence: share them, with this credit, under CC BY-SA 4.0.

What was done: each note (G3 to B6, 38 of them) was cut from the recording
with its own attack and tail, levelled to the same sustained loudness, made
mono and encoded as AAC (`c-<MIDI note>.m4a`). `samples.json` lists each
note's tuning as recorded, in cents above A=440 equal temperament, which the
page corrects when it plays them.
